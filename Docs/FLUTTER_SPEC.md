# Bottle Sort — спецификация Flutter-версии (для порта на Unity)

Источник: `E:\Projects\Flutter\bottle_sort`. GS = `lib/game/screens/game_screen.dart`.
`bottle_widget.dart` и `game_button.dart` — мёртвый код; бутылки рисует `_AnimatedBottlePainter` (GS:3632).

## 1. Правила
- Вместимость 4 слоя (GS:70). Каждого цвета ровно 4 единицы. Палитра 10 цветов (GS:74-85).
- 1000 уровней (clamp 1..1000 в GS:197; `_goNextLevel` GS:1140 не клампит — баг).
- Генерация `_generateLevel` (GS:303-480):
  - Уровни 1–3 — обучающие, ручные: 2/3/4 цвета + 2 пустые (GS:307-338).
  - С 4-го: `colorCount = min(5 + (L-4)/2, 10)`; бутылок = цвета + 2 пустые.
  - Seed: `Random(L*7919 + colorCount*97)`, попытка: `salt = outer.nextInt(100000)+attempt`, `rnd = Random(L*104729 + salt*6151)`.
  - Паттерн `(L+salt)%4`: 0 — shuffle; 1 — «змейка» `(c+i+salt)%n` + swap каждого 3-го; 2 — пары (c,c+1,c,c+2); 3 — четвёрки (c,c+1,c+2,c).
  - Нарезка по 4, +2 пустые, Fisher-Yates по бутылкам. До 40 попыток с фильтром: нет собранных бутылок (L>4), ровно 2 пустые, бутылок с ≥3 разными цветами ≥ max(3,n-2), есть повтор верхнего цвета. Фолбэк `makeMixedState(L*31)`.
  - **Проверки решаемости нет.** Dart Random не воспроизводится в C# — в Unity раскладки будут другие (нужен свой генератор + солвер).
- Переливание: тап — выбор, повторный тап — снять (GS:935). `_canPour` (GS:970): источник не пуст, в цели < 4, цель пуста или верх совпадает. Объём = min(непрерывный верхний отрезок, свободное место) (GS:982). Неверный ход — снять выбор + звук ошибки. Параллельные переливания разрешены для разных бутылок.
- Победа: каждая непустая бутылка — 4 одного цвета (GS:616, GS:1426). Поражения/тупиков нет.
- Undo (GS:1093) — история без лимита, 1 тикет за шаг. Restart (GS:1126) — бесплатно, та же раскладка, убирает добавленные бутылки. +Бутылка (GS:1165) — макс 9 бутылок при L≤3, иначе 14. Hint (GS:1192) — первый допустимый ход по индексам.
- Звёзды (GS:1452), moves = длина истории: 3★ если moves ≤ max(8, colors*4+L); 2★ если ≤ max(14, colors*6+2L); иначе 1★.
